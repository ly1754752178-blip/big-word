## 1. 目标与范围

### 目标
将当前以深色玻璃拟态为主的入口菜单，全面改造成**日式日常系 Galgame + 人生模拟**的柔和、温暖、学园风视觉；同时把右上角视频背景播放器改造成**左侧预览图 + 右侧控制区**的横向矩形播放器，并保持同一套 Galgame 风格。

### 改动范围
- `src/app/TavernLobby.tsx`：主菜单整体布局、按钮样式、信息面板、标题横幅。
- `src/components/lobby/VideoBackground.tsx`：右上角视频背景播放器控件外观，不改动底层视频/音频播放逻辑。
- `src/styles/globals.css` / `tailwind.config.ts`：补充需要的装饰性工具类与色值（尽量复用现有 token，必要时新增少量）。
- 不改动：开场光球 `OpeningOrb`、各 SillyTavern 弹窗内容、路由与状态流转、BGM 播放器 `BgmPlayer`（游戏内顶部栏那个）。

## 2. 参考图风格提炼

两张参考图共同呈现出：

- **底色**：暖调教室/樱花场景，整体偏奶油色、浅木色、柔粉色。
- **卡片/按钮**：大圆角、浅色半透明底、细腻描边、微投影；hover 时轻微上浮并泛出温柔光晕。
- **标题**：横幅式标签，带樱花、缎带等装饰元素，衬线或圆润字体感。
- **信息面板**：右侧竖向卡片，分层展示「最近存档 / 通知 / BGM」等信息。
- **播放器**：参考图 1 底部有「缩略图 + 章节名 + 播放控制 + 音量滑块 + 版本号」的横向长条，与本次要重制的右上角播放器形态一致。

## 3. 设计方案

### 3.1 总体布局

TavernLobby 全屏铺满当前视频背景，上方覆盖一层**由下往上渐淡的暗角遮罩**（保留参考图 1 底部略深的氛围，同时保证文字可读）。

主要元素：

- **左上角标题横幅**：带樱花装饰角的奶油色/木色横幅，显示游戏标题（复用项目名或固定文案）。
- **左侧主菜单**：6 个竖向排列的大圆角按钮（开始游戏、继续游戏、世界书、API 配置、预设、设置）。
- **右侧信息面板**：双层卡片结构，展示「最新存档 / 通知 / 当前 BGM」。
- **右上角横向播放器**：矩形，左侧为当前视频缩略图方框，右侧为控制按钮与进度/音量。
- **底部中央/右下**：版本号、 subtle 装饰线。

### 3.2 色彩与质感

以项目设计系统为基础，向参考图做暖调偏移：

- 主背景卡片：`rgba(255, 251, 244, 0.82)`（奶油白，参考 `--cream-50`）
- 描边：`rgba(218, 205, 190, 0.6)` 到 `rgba(232, 141, 79, 0.35)`（温暖金棕）
- 按钮 hover：浅木色渐变 + 樱花粉微光
- 强调色：琥珀/珊瑚/天空蓝点缀，保持柔和低饱和
- 阴影：柔和弥散，避免黑色重影

新增/复用的 token：

```css
--gal-cream: #FFF8F0;
--gal-wood: #E8D5C4;
--gal-sakura: #F8C3CD;
--gal-ink: #5A4A3D;
--gal-border: rgba(190, 170, 150, 0.5);
```

### 3.3 主菜单按钮

- 尺寸：宽 220–260px，高 52–56px，圆角 16px。
- 样式：奶油色底 + 金棕色 1px 描边 + 内阴影高光；左侧 icon + 右侧文字。
- Hover：translateX(6px)、背景渐变到浅木色、边框变亮、出现樱花粉外发光。
- Active：scale 0.98。
- 焦点/无障碍：保留 `aria-label` 与键盘焦点环。

### 3.4 右侧信息面板

- 容器：奶油色圆角卡片（20px），带双层边框与顶部装饰线。
- 分区：
  - 最新存档：日期 + 时间
  - 通知：1–2 条游戏内提示
  - BGM：当前曲目名
- 装饰：樱花角标、细分隔线、小图标。

### 3.5 右上角视频背景播放器

形态：**横向矩形**，不再使用当前竖向小面板。

- 左侧：约 84×84px 的方框，显示当前视频首帧/封面预览图（视频加载后取 `videoRef.current` 画面绘制到 canvas，或 fallback 到樱花/风景占位图）。
- 右侧：
  - 顶行：曲目名（`《{name}》`），小字号，省略。
  - 中行：播放/暂停、上一曲、下一曲。
  - 下行：音量图标 + 滑块、静音切换。
- 容器：奶油色/浅木色底，圆角 16px，细腻描边与阴影；控件使用 Lucide 图标，色调与菜单统一。
- 保持现有播放逻辑：视频循环、音频结束自动切歌、洗牌、静音记忆等，只改视觉层。

### 3.6 字体

标题使用更圆润/略有手写感的字体栈：

```css
font-family: 'M PLUS Rounded 1c', 'Noto Sans JP', 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

正文仍用现有 `font-body`。

### 3.7 动效

- 菜单入场：从左侧淡入 + 轻微右移，stagger 60ms。
- 标题横幅：轻微上下浮动（参考图 1 标题带呼吸感）。
- 按钮 hover：200ms ease-out，上浮 + 光晕。
- 播放器封面：播放时轻微 pulse，切歌时淡入淡出。

## 5. 风险与兼容

- 视频封面图获取依赖视频已加载，需处理 loading 占位与错误 fallback。
- 当前菜单按钮使用 inline style 的 hover，需要迁移到 Tailwind + CSS 工具类以保证可维护。
- 右侧信息面板目前为静态展示，没有真实存档/通知数据源；先用 mock 占位，并预留接口，避免阻塞主流程。
- 保持所有弹窗（ChatModal、LorebookModal 等）正常打开与关闭。
- 保持 `requestFullscreen` 与 `orb-clicked` 事件不变。
